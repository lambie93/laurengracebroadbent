**Personal Website 1**
**About**
My first personal website is a fun project I have been working on while learning HTML, CSS, and JavaScript. I created it as a way to practice web development and build a website that reflects my personality.

This website is still a work in progress, but it currently includes information about my school schedule, extracurricular activities, and some of my favorite things. I am continuing to add new sections, improve the design, and experiment with new web development techniques as I learn more.

I previously submitted an earlier version of this website to Hack Club Boba Drops. Since then, I have expanded the website from a single page into several pages, added new content, and made various design improvements.

**Tech Stack**
This project was created using HTML and CSS. HTML was used to structure and organize the website’s content, while CSS was used to design the layout, colors, fonts, and overall appearance. I used Visual Studio Code to write and edit the code.

**How It Was Made**
I built this website using the fundamental concepts of HTML, CSS, and JavaScript. To create the rotating TV show roulette feature, I followed a YouTube tutorial and adapted the techniques I learned to fit the design and functionality of my website.

**Challenges and Improvements**
One challenge I encountered was troubleshooting parts of the tutorial that did not work as expected and adapting the code to fit my website. I also had to learn how CSS Flexbox works and determine how to use it effectively to organize and position content on the page.
